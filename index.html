Everything in the tray

Built for the way you actually share.

One small app. No accounts, no browser tab, no dragging files around.

Freeze & select

The screen stills and dims the instant you press the hotkey, so you capture exactly what you saw. Area, window or full screen.

Quick editor

Arrows, curved arrows, boxes, circles, text, pen, marker and blur. Paste or drop pictures in, pick any colour, undo anything.

Screen recording

Record an area, a window or the whole screen up to 60 fps. Desktop audio and your mic on separate tracks, with pause and mute.

Real video editor

Trim, split, cut out, change speed, mute any stretch of any sound track, and add layers with keyframes that move over time.

Link formats

Copy a plain URL, a direct link, Markdown or BBCode, or copy the image itself. Progress, cancel and retry on every upload.

Private by default

Photo metadata is stripped before upload and your API key is stored encrypted for your account. Nothing goes anywhere but Haunt.

Questions

Good to know.

Windows says “Windows protected your PC”

Poltergeist isn’t code-signed yet, so SmartScreen warns about new apps. Click More info → Run anyway. If you downloaded the zip in a browser, right-click it → Properties → Unblock before unzipping avoids the warning.

macOS says it can’t verify the developer

Right-click Poltergeist in Applications and choose Open, then confirm. You only do this once. Screen Recording permission is requested the first time you capture.

Why does recording ask to download ffmpeg?

Windows recording and the video editor use ffmpeg, which can’t be bundled for licensing reasons. Poltergeist downloads it once (about 30 MB) into your user folder. Screenshots and uploads work without it.

Where do I get an API key?

Open your Haunt dashboard, create an API key, name it anything, and enable Upload and Read under Image Host. Paste it into Settings → Account. It’s stored encrypted on your computer.

Is my screen sent anywhere else?

No. Captures go from your computer straight to your Haunt Image Host and nowhere else. Photo metadata is removed first, by default.
